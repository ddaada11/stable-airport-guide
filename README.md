| **IEPL / IPLC 专线** | 内网专线，不经过公网 | 最稳，几乎不掉速 | 15~30 元/月 |
| **BGP 中转** | 国内 BGP 入口 + 跨境中转 | 较稳，偶有波动 | 12~25 元/月 |

> 三种线路的成本差就是价格差。**不存在「又便宜又是专线」这种事**——低于 8 元/月还说自己是专线的，基本都是公网中转包装的。

## 常见问题

### 稳定机场和便宜机场差在哪？
主要差在线路成本。低价档走公网直连，晚高峰会堵；专线档租的是 IEPL / IPLC 内网通道，同样 100G 流量，专线成本是直连的 3~5 倍。这就是为什么专线机场最低也要 15 元/月。

### IEPL 和 IPLC 有什么区别？
两者都是内网专线，主要区别是接入方式和运营商。对普通用户来说：**都不用管，看价格和节点数量就行**。宣传上说自己是 IPLC 但月付只要 5 元的，基本是公网中转包装的。

### 晚高峰掉速怎么判断？
工作日 21:00–22:00 连续测三天，取最低值，不是取最快那次。这 7 家大多自带线路检测页，注册前可以先看一眼自己所在地区到各入口的延迟。

### 这份清单的价格准吗？
每个套餐都是登录各家后台「购买订阅」页截图抄下来的，标注了核实日期（2026-11-14）。不写第三方渠道抄来的数字——那类价格通常已经过期。机场改价不会通知任何人，下单前还是以官网当前页面为准。

### 预算有限，但又想要稳一点，怎么选？
选「公网中转 / 优化」那一档（宇宙云、二猫云），比纯直连稳，价格也比专线低。或者看另一份清单：[便宜机场推荐](https://github.com/ddaada11/cheap-airport-guide) —— 那里是 1~6 元档。
